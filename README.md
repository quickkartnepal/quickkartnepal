# Quick Kart Project

Create a complete, modern, and high-converting eCommerce dropshipping website for my brand “Quick Kart Nepal”.

This website must have TWO INTERFACES:
1. Customer Interface (default landing page)
2. Admin Panel (hidden login access from footer)

🌐 GENERAL DESIGN & BRANDING
----------------------------------------
- Design style should be clean, modern, and premium
